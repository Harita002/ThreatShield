# ThreatShield: Machine Learning Based Insider Threat Detection

## Overview
ThreatShield is a machine learning mini project that analyzes employee activity data to identify potentially suspicious behavior. It uses a classification model to categorize employee records as normal or suspicious.

## Objectives
- Analyze employee activity data.
- Perform data preprocessing and feature preparation.
- Train a machine learning classification model.
- Evaluate model performance using standard metrics.
- Predict potentially suspicious employee behavior.

## Technologies Used
- Python
- Pandas and NumPy
- Scikit-learn
- React.js
- Spring Boot
- MySQL
- Docker

## Workflow
1. Load the employee activity dataset.
2. Clean and preprocess the data.
3. Prepare features for model training.
4. Train the classification model.
5. Evaluate model performance.
6. Predict whether employee records are normal or suspicious.

## Key Features
- Employee activity data analysis
- Machine learning-based classification
- Threat prediction
- Model performance evaluation
- Dashboard for viewing analysis results
